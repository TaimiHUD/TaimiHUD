# TaimiHUD

https://taimihud.com

A cross-platform Timers, Commander's Markers and Pathing addon, leveraging [Raidcore Nexus](https://raidcore.gg/Nexus) or [ArcDPS](https://www.deltaconnected.com/arcdps/).
